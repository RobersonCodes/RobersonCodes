# Hero generation prompt

Mode: built-in image generation tool. Use case: `stylized-concept`.

> Create a cinematic, photorealistic 3D rendering of planet Earth at night, positioned on the right half of a very wide dark composition, with South America clearly visible and Brazil near the visual focus. City lights glow naturally; a thin electric-blue atmosphere wraps the planet. Add restrained cloud-network visualization: sparse cyan nodes, subtle connection arcs, a few orbital lines, and tiny infrastructure telemetry points. The overall feeling combines premium cloud infrastructure, cyber engineering, NASA-grade visualization, and modern SaaS polish. Use a near-black graphite and deep navy space backdrop, faint technical grid and minimal particles, with seamless dark falloff across the left half. Keep generous clean negative space on the left for later typography. Use cinematic, realistic, sophisticated lighting with no neon overload. No text, letters, numbers, logos, watermark, interface panels, cartoon style, fantasy continents, or exaggerated lens flare. Earth geography must be realistic and South America recognizable.

The generated raster was used only as the visual background. All typography, status labels, grid lines and interface framing were added deterministically in `hero-render.html` before the final WebP export.
