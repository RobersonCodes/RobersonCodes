## Projetos principais

### [TireMax ERP](https://github.com/RobersonCodes/Tiremax)

ERP SaaS multi-tenant para borracharias e centros automotivos, com clientes, veículos, estoque, PDV, ordens de serviço, financeiro e módulo fiscal.

- **Stack:** Node.js, Express, React, Prisma e PostgreSQL
- **Qualidade:** 148 testes automatizados e CI com GitHub Actions
- **Arquitetura:** isolamento estrutural por tenant com AsyncLocalStorage e Prisma Client Extension
- **Produção:** [tiremax.shop](https://tiremax.shop)

### [Gestão de Solicitações Internas](https://github.com/RobersonCodes/gestao-de-solicitacoes-internas)

Plataforma corporativa multiempresa para solicitações de compras, TI, RH e manutenção.

- **Stack:** TypeScript, React, Node.js, Prisma e PostgreSQL
- **Engenharia:** RBAC, workflows versionados, SLA, auditoria e transactional outbox
- **Qualidade:** testes unitários e de integração com PostgreSQL real, CI e documentação Swagger

### [Sistema de Gestão de Saúde](https://github.com/RobersonCodes/Sistema-de-saude)

Backend para gestão municipal de pacientes, profissionais, unidades, agendas e consultas.

- **Stack:** Java 17, Spring Boot 3, Spring Security, JWT e MySQL
- **Regras:** máquina de estados e bloqueio de duplo agendamento
- **Testes:** integração com JUnit, Spring Boot Test e H2
- **Integrações:** OpenAI e estrutura demonstrativa para e-SUS APS/RNDS

### [Arquitetura de API Multi-tenant](https://github.com/RobersonCodes/oliveira-systems-api-architecture)

ADRs e decisões técnicas para uma fundação REST multi-tenant com Node.js, TypeScript, PostgreSQL e Redis.
