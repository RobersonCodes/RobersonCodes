# README Design System

## Direction

Dark Engineering + Developer OS + Cyber Terminal + Premium SaaS + 3D Technology.

## Tokens

| Role | Value | Use |
|---|---|---|
| Canvas | `#03070D` | Hero and primary visual surfaces |
| Surface | `#08101C` | Metric and project panels |
| Border | `#18324F` | Technical dividers and card outlines |
| Primary accent | `#3483F6` | Navigation, focus and identity |
| Secondary accent | `#31C7D7` | Network and infrastructure details |
| Success | `#39D98A` | Explicit passing/online states only |
| Text | `#F8FAFC` | Headlines |
| Muted text | `#9AA7B7` | Supporting copy |

## Typography

- Display: system sans-serif, heavy and tightly tracked.
- Technical labels: system monospace / Courier New, uppercase and widely tracked.
- README body: GitHub's native interface typography for accessibility and rendering consistency.

## Layout

- Hero source canvas: 1600 × 700.
- Mobile hero source canvas: 800 × 950, selected below 600 CSS pixels.
- Project cards: 1200 × 250.
- Engineering panel: 1200 × 300.
- Screenshots preserve their captured 1264 × 625 aspect ratio.
- All primary images are fluid through `width="100%"` and retain intrinsic proportions.

## Asset policy

- WebP for photographic or screenshot content.
- SVG for deterministic cards, metrics and official technology marks.
- No JavaScript, external CSS, iframe, WebGL or dynamic client runtime is required by the README.
- Important information is repeated as readable text; color is never the only status signal.
